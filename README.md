## ✨ Design System & Aesthetic

- **Color Palette**: Clean obsidian white (`#FFFFFF`) background with subtle warm stone cards (`#FBFBFC`) and brushed gold accents (`#C5A059`).
- **Typography**: Cormorant Garamond serif headings paired with clean Inter sans-serif body.
- **Mobile-First & Fully Responsive**: Optimized across smartphones, tablets, laptops, and ultra-wide desktop displays.
- **Pure Web Standards**: Built using semantic HTML5, modern CSS3 (Flexbox/CSS Grid), and vanilla JavaScript without external framework bloat.

## 🚀 How to Run Locally

Open `index.html` in any modern web browser, or run a local HTTP server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```

Then visit `http://localhost:8000` in your browser.
